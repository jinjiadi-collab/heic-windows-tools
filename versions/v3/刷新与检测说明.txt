HEIC 刷新与检测补丁 v3

已经安装 v2 的电脑只需要这个小补丁，不必重新下载组件。
解压后使用日常看照片的 Windows 账户运行；一般不需要右键管理员运行。

1-刷新缩略图.cmd
运行前先结束文件复制和移动，并关闭照片应用。
会开启当前用户的缩略图显示，结束并重新启动当前会话的文件资源管理器（桌面/任务栏可能短暂消失，文件夹窗口可能关闭），只清理当前用户 Explorer 目录中的 thumbcache_*.db 缩略图缓存。
不会删除照片，不会清理其他文件或磁盘，不修改组织策略，不重启电脑。
修改前的 IconsOnly 值会备份到日志目录中的 thumbnail-setting-*.json。
部分缓存若仍被占用会明确报告，不会假称全部清理成功。
刷新只解决显示设置、缓存或 Explorer 尚未更新的问题，不保证修复图片解码错误。

2-检测打不开的图片.cmd
弹出文件选择窗口，选择另一台电脑上打不开的那张 HEIC/HEIF 原图。
检测当前账户 HEIF/HEVC/照片应用安装状态、Windows 版本、缩略图策略及所选文件的 WPF/WIC 解码结果；读取第一帧的一个像素以确认实际解码。
不会上传图片、转换图片、修改原图或重设默认应用。
若检测能解码但双击打不开，请右键图片→打开方式→照片，确认使用微软照片应用。
若检测失败，请提供日志及照片应用的具体报错；WPF/WIC 检测本身不代表照片应用或资源管理器的所有解码路径。

3-只检查组件状态.cmd
只读检查组件状态和相关显示设置，不清缓存、不重启资源管理器。

日志位置：%LOCALAPPDATA%\HEIC-OfflineExtensions\Logs\refresh-v3-*.txt
日志包含 Windows 用户名、系统版本以及选择图片的路径，发给别人前可自行遮去这些个人信息。

验证：脚本语法检查通过；当前电脑的只读状态检查、正常 PNG 图片实际像素解码、损坏样本的报错流程均验证通过。
尚未在目标电脑验证 HEIC 原图，也未在本机执行清缓存/重启 Explorer 分支，以免打断当前工作。
